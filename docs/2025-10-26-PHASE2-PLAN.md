### Merge Process

#### Step 1: Verify Clean Merge

```bash
# Switch to main feature branch
git checkout feat/flowbite-dev-go

# Update from remote
git pull origin feat/flowbite-dev-go

# Check for conflicts with backend branch
git merge --no-commit --no-ff feat/auth-backend-validation

# If no conflicts, abort this test merge
git merge --abort
```

#### Step 2: Merge Backend Branch

```bash
# Merge backend validation branch
git merge feat/auth-backend-validation -m "merge(auth): backend password, NIK, NIP, position validation"

# Verify merge successful
git log --oneline -3
```

#### Step 3: Merge Frontend Branch

```bash
# Merge frontend fix branch
git merge feat/auth-frontend-nip-fix -m "merge(auth): NIP validation frontend enforcement"

# Verify merge successful
git log --oneline -3
```

#### Step 4: Verification

```bash
# Verify no conflicts
git status

# Verify all commits present
git log --oneline feat/auth-backend-validation..HEAD
git log --oneline feat/auth-frontend-nip-fix..HEAD

# Should show 0 commits (all merged)
```

#### Step 5: Push to Remote

```bash
# Push merged changes
git push origin feat/flowbite-dev-go

# Verify push successful
git branch -v
```

### Rollback Plan

**If Critical Issues Found**:

1. **Immediate Rollback**:
   ```bash
   # Switch to previous stable version
   git checkout <previous-stable-commit>
   
   # Rebuild and redeploy
   go build -o exe/selly-backend.exe cmd/server/main.go
   
   # Restart services
   docker-compose restart
   ```

2. **Database Rollback**:
   - Restore from pre-deployment backup
   - Verify data integrity
   - Run post-restore tests

3. **Communication**:
   - Notify stakeholders of rollback
   - Document issue that caused rollback
   - Schedule post-mortem
