# Pengajuan Bulanan - Quick Fix Reference

**Fix Date**: 2025-11-10

## Problem in 1 Line

Component calls `supabase.auth.getSession()` (Supabase auth) but should use Go backend session tokens from localStorage.

## Root Cause

```
❌ supabase.auth.getSession() → Returns Supabase session (empty with Go backend auth)
✅ localStorage.getItem("selly_auth_token") → Returns Go backend session token
```

## 3 Critical Fixes

### Fix 1: fetchRekapData() - Line 135-147

**REMOVE THIS**:
```typescript
const session = await supabase.auth.getSession();
const token = session.data.session?.access_token;
```

**ADD THIS**:
```typescript
const token = localStorage.getItem("selly_auth_token");
if (!token) {
  toast.error("Sesi autentikasi tidak ditemukan. Silakan login kembali.");
  router.push("/login");
  return { totalCount: 0 };
}
```

### Fix 2: API Endpoint

**CHANGE**: `/api/data-rekam/pengajuan-bulanan`

**TO**: `${process.env.NEXT_PUBLIC_API_URL}/api/v1/data-rekam/pengajuan-bulanan`

(Use Go backend directly, not Next.js proxy)

### Fix 3: handleSubmit() - Line 205-260

**REMOVE THESE**:
```typescript
const { data: existingData, error: fetchError } = await supabase
  .from("pengajuan_bulanan")
  .select("id")
  .eq("id", editData.id)
  .maybeSingle();

const { error } = await supabase
  .from("pengajuan_bulanan")
  .insert(dataToSave);
```

**ADD THIS** (use API route):
```typescript
const token = localStorage.getItem("selly_auth_token");
const response = await fetch(
  "/api/data-rekam/pengajuan-bulanan",
  {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${token}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify(dataToSave),
  }
);
```

## Why This Works

| Component | Before ❌ | After ✅ |
|-----------|----------|---------|
| Token Source | `supabase.auth.getSession()` (returns null) | `localStorage.getItem("selly_auth_token")` (has value) |
| API Endpoint | `/api/data-rekam/pengajuan-bulanan` (Next.js proxy) | `/api/v1/data-rekam/pengajuan-bulanan` (Go backend) |
| Direct DB Calls | `supabase.from().insert()` (RLS violation) | API route with service role (works) |
| Auth Flow | Supabase auth (wrong system) | Go backend auth (correct system) |
