## 🔍 Quick Answer Reference

### **"What is PengaduanBulananHeader?"**
📖 **Reference**: [Refinement Report - Component Features](#refinement-report)

Enterprise-grade page header component with optional real-time statistics display for the SELLY complaint management system. Implements Flowbite Pro patterns with glass-morphism design, full accessibility compliance, and responsive mobile-first layout.

---

### **"How do I use it?"**
📖 **Reference**: [Quick Reference - Usage Examples](#quick-reference---usage-examples-section)

**Basic usage**:
```tsx
<PengaduanBulananHeader />
```

**With statistics**:
```tsx
<PengaduanBulananHeader
  showStats={true}
  totalComplaints={150}
  pendingComplaints={25}
  resolvedComplaints={125}
/>
```

For more examples, see Quick Reference Guide.

---

### **"What props does it have?"**
📖 **Reference**: [Quick Reference - Props Interface](#quick-reference---props-interface-section)

```typescript
interface PengaduanBulananHeaderProps {
  title?: string;                    // Default: "Pengaduan Bulanan"
  description?: string;              // Default: Full description
  showStats?: boolean;               // Default: false
  totalComplaints?: number;          // Default: 0
  pendingComplaints?: number;        // Default: 0
  resolvedComplaints?: number;       // Default: 0
  className?: string;                // Custom CSS classes
  delay?: number;                    // Animation delay (seconds)
  disableAnimations?: boolean;       // Disable animations
}
```
