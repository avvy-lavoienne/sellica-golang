## Common Pitfalls to Avoid

### ❌ Column Name Mismatches

```go
// ❌ WRONG - Snake case vs camelCase confusion
NikSalahRekam string `db:"nikSalahRekam"`  // Database is nik_salah_rekam!

// ✅ CORRECT - Match exactly with database
NikSalahRekam string `db:"nik_salah_rekam"`
```

### ❌ Missing Position Gaps

Note: Column positions jump (11 → 13, 14 → 18, 18 → 19). This is expected in database; don't add fake columns.

### ❌ Type Mismatches

```go
// ❌ WRONG - Treating UUID as string
UserID string `db:"user_id"`  // Should be uuid.UUID

// ✅ CORRECT - UUID type
UserID uuid.UUID `db:"user_id"`
```

### ❌ Optional Field Handling

```go
// ❌ WRONG - Not using pointers for optional nullable fields
EstimasiTanggalPerekaman time.Time  // Will fail if null

// ✅ CORRECT - Use pointers for nullable fields
EstimasiTanggalPerekaman *time.Time
```

### ❌ NIK Validation

```go
// ❌ WRONG - No NIK validation
if req.NikSalahRekam == "" { ... }  // Should validate format too

// ✅ CORRECT - Full NIK validation
if len(req.NikSalahRekam) != 16 {
  return errors.New("NIK must be 16 digits")

if !isNumeric(req.NikSalahRekam) {
  return errors.New("NIK must contain only digits")
```
