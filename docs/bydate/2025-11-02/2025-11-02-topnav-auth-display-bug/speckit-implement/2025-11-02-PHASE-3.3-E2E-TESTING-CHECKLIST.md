## 📋 Pre-Test Checklist

Before starting manual E2E testing, verify:

- [ ] Frontend development server running: `pnpm dev` (http://localhost:3000)
- [ ] Backend server running: `go run cmd/server/main.go` (http://localhost:8080)
- [ ] Browser: Chrome, Firefox, or Safari (latest version)
- [ ] Browser DevTools open (F12) to monitor console for errors
- [ ] Network tab available to check API calls
- [ ] Credentials ready for testing:
  - [ ] Test user email (e.g., test@example.com)
  - [ ] Test user password
  - [ ] Alternative test user (optional, for comparison)

## 🧪 Scenario 1: User Display Verification

**Purpose**: Verify TopNav displays correct user information after login  
**Duration**: 5 minutes  
**Prerequisites**: Both servers running, user credentials available

### Steps:

1. **Start Test**
   - [ ] Open browser to http://localhost:3000
   - [ ] Verify landing page loads
   - [ ] Note: No user data displayed initially

2. **Navigate to Login**
   - [ ] Click "Login" button/link
   - [ ] Verify login page loads
   - [ ] URL should be: http://localhost:3000/login

3. **Enter Credentials**
   - [ ] Enter test user email in email field
   - [ ] Enter test user password in password field
   - [ ] Note all fields present and editable

4. **Submit Login**
   - [ ] Click "Sign In" button
   - [ ] Monitor network tab: Should see auth API calls
   - [ ] Monitor console: Should see no errors
   - [ ] Wait for redirect

5. **Verify Dashboard**
   - [ ] Page redirects to dashboard (http://localhost:3000/dashboard or similar)
   - [ ] Dashboard content loads
   - [ ] TopNav is visible at top of page

6. **Verify TopNav Display**
   - [ ] **Avatar**: 
     - [ ] If user has profile picture: Image displays correctly
     - [ ] If no profile picture: User initials display (e.g., "JD" for John Doe)
     - [ ] Avatar has proper size and styling
   - [ ] **Email Address**:
     - [ ] Test user email displays in TopNav
     - [ ] Email format is correct
     - [ ] Email is readable (good contrast)
   - [ ] **User Name**:
     - [ ] Full name displays if available
     - [ ] Falls back to email prefix if name not available
     - [ ] Text is readable and properly formatted
   - [ ] **User Menu**:
     - [ ] Dropdown menu button present
     - [ ] Clicking avatar/email opens user menu
     - [ ] Menu shows user options

7. **Console Check**
   - [ ] Open browser DevTools (F12)
   - [ ] Check Console tab
   - [ ] [ ] NO red error messages
   - [ ] [ ] NO warnings related to auth/context
   - [ ] Note any relevant info messages

### Expected Result:
✅ **PASS**: All user information displays correctly with no console errors  
❌ **FAIL**: Missing data, incorrect display, or console errors

**Prerequisites**: Logged in, on dashboard, user menu accessible

   - [ ] User information visible in TopNav

   - [ ] Navigate to Settings page (if available) or Profile page
   - [ ] URL should be: http://localhost:3000/settings or /profile

     - [ ] Find profile picture/avatar upload input
     - [ ] Upload a new image file (PNG/JPG, <5MB)
     - [ ] OR update name field to different name
   - [ ] Save changes
   - [ ] Monitor network tab: Should see update API call
   - [ ] Wait for success confirmation

3. **Return to Dashboard**
   - [ ] Click Dashboard link or navigate to dashboard

     - [ ] If name changed, TopNav shows new name

   - [ ] Open DevTools Console
   - [ ] [ ] NO new error messages
