## 🔍 Regression Testing Purpose

**Why**: Changes to TopNav/authentication context could break:
- Page rendering
- Layout calculations
- Component interactions
- User session management
- Data loading on protected pages
- Public page access

**What to Look For**:
- ❌ 404 errors (page not found)
- ❌ 403/401 errors (auth failures)
- ❌ Broken layouts
- ❌ Missing content
- ❌ Console errors
- ❌ Styling issues
- ❌ Navigation broken
- ❌ Forms not submitting

---

## 🐛 Critical Issues to Watch For

### Showstoppers (Must Fix Before Release)

**Check for these critical issues on each page**:

1. **Auth Context Broken**
   - [ ] User data undefined on protected pages
   - [ ] App crashes when accessing pages
   - [ ] 500 errors appearing

2. **Layout Issues**
   - [ ] TopNav breaks page layout
   - [ ] Content hidden or overlapped
   - [ ] Horizontal scrolling introduced

3. **Navigation Broken**
   - [ ] Can't navigate between pages
   - [ ] Links don't work
   - [ ] Navigation menu broken

4. **Data Not Loading**
   - [ ] Protected page data doesn't load
   - [ ] Console shows fetch errors
   - [ ] 401/403 errors for user endpoints

5. **Console Errors**
   - [ ] Red errors in console
   - [ ] Auth-related exceptions
   - [ ] React errors

### Major Issues (Should Fix)

- Typography/styling broken
- Forms not fully functional
- Performance degradation
- Mobile layout issues
