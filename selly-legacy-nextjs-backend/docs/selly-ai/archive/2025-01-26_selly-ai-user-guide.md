# SELLY AI User Guide
**Date**: 2025-01-26  
**Version**: 3.0  
**Type**: User Documentation

## 🎯 Overview

SELLY is now an AI-powered chatbot that understands Indonesian language and provides intelligent insights, suggestions, and follow-up questions. This guide shows you how to interact with the enhanced AI features.

## 🚀 Getting Started

### **Accessing SELLY**
1. Navigate to the dashboard
2. Look for the SELLY chatbot interface
3. Click to open the chat window
4. Start typing your questions in Indonesian

### **AI Enhancement Indicators**
When AI enhancement is active, you'll see:
- 🧠 **AI Insights** section
- 💡 **Saran** (Suggestions) section  
- ❓ **Pertanyaan Lanjutan** (Follow-up Questions) section
- Enhanced response time indicators

## 💬 How to Use SELLY AI

### **Basic Interaction**
```
You: "Halo SELLY"
SELLY: "Halo! 👋 Saya SELLY, asisten AI cerdas Anda..."
```

### **Enhanced AI Response Format**
```
[Basic Response Content]

🧠 AI Insights:
• 📊 Volume data tinggi - pertimbangkan analisis trend
• 🔍 Data tersedia - bisa dilakukan analisis lebih lanjut

💡 Saran:
• Coba pertanyaan yang lebih spesifik
• Gunakan kata kunci yang jelas

❓ Pertanyaan Lanjutan:
• Ada yang ingin ditanyakan lebih lanjut?
• Perlu bantuan dengan data lain?
```

## 🔧 Troubleshooting

### **AI Enhancement Not Showing**
**Symptoms**: Only basic responses without AI insights
**Solutions:**
1. Wait a few seconds for AI processing
2. Try refreshing the page
3. Check if TensorFlow is enabled in settings

### **Slow Response Times**
**Symptoms**: Long delays before getting responses
**Causes**: AI model loading or processing
**Solutions:**
1. First query may be slower (model loading)
2. Subsequent queries should be faster
3. Complex queries take more processing time

### **Unclear AI Suggestions**
**Symptoms**: AI suggestions don't seem relevant
**Solutions:**
1. Try more specific questions
2. Use clear Indonesian keywords
3. Provide more context in your query
