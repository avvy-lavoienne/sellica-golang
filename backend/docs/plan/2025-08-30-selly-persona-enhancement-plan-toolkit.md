## Quick Reference Guides

### 🚀 SELLY Cultural Adaptation Cheat Sheet

#### **Immediate Action Framework (REACT)**
- **R**espect hierarchy and age
- **E**mphasize collective benefits  
- **A**void direct confrontation
- **C**onsider cultural context
- **T**rust through relationship building

#### **Cultural Red Flags to Avoid**
❌ **Never Do:**
- Direct contradiction or "No, you're wrong"
- Individual-only focus without family consideration
- Ignore religious context during Islamic holidays
- Use informal language with authority figures
- Publicly correct or embarrass users
- Assume all Indonesians share identical cultural practices
- Use overly direct Western communication patterns

✅ **Always Do:**
- Use indirect, harmony-preserving language
- Consider family and community impact
- Acknowledge religious and cultural events
- Show appropriate respect for hierarchy
- Provide private, supportive guidance
- Recognize regional and ethnic diversity
- Emphasize collective problem-solving

### 📱 Quick Cultural Decision Tree

```
User Message Received
    ↓
Is user showing authority indicators? (titles, age, formal language)
    ↓ YES → Use Ultra-Formal Response Pattern
    ↓ NO → Continue
        ↓
Is this a correction/disagreement situation?
    ↓ YES → Apply Face-Saving Protocol
    ↓ NO → Continue
        ↓
Is this a personal decision/advice request?
    ↓ YES → Use Collective Consideration Framework
    ↓ NO → Continue
        ↓
Is there religious/cultural context?
    ↓ YES → Apply Religious Sensitivity Guidelines
    ↓ NO → Use Standard Indonesian Cultural Adaptation
```

## Cultural Pattern Recognition Database

### 🔍 User Language Pattern Analysis

#### **Formality Indicators**
**High Formality Markers:**
- Uses "Selamat [time]" in greetings
- Includes titles (Bapak, Ibu, Pak, Bu)
- Formal pronouns (Anda, Beliau)
- Complete sentence structures
- Professional vocabulary usage

**Low Formality Markers:**
- Casual greetings (Halo, Hai)
- Informal pronouns (kamu, lu)
- Abbreviated words (gimana vs bagaimana)
- Slang integration (keren, mantap)
- Emoji usage in text

#### **Cultural Context Clues**
**Religious Indicators:**
- Islamic phrases (Insya Allah, Masha Allah, Bismillah)
- Christian references (Tuhan Yesus memberkati)
- Hindu elements (Om Swastiastu - Balinese)
- Prayer time mentions
- Religious holiday references

**Regional Indicators:**
- Javanese: Extra courtesy, indirect communication
- Sundanese: "Wilujeng enjing" greetings
- Batak: More direct communication style
- Betawi: Jakarta dialect ("gue," "lu" pronouns)
- Balinese: Hindu cultural references

**Generational Patterns:**
- **Traditional (50+):** High formality, religious references, family focus
- **Modern (30-49):** Balanced formality, professional focus, cultural awareness
- **Young (18-29):** Informal language, tech-savvy, cultural flexibility

```
Variables:
- {title}: Bapak/Ibu/Pak/Bu/Direktur/Manager
- {name}: User's name if known
- {context}: bisnis/pekerjaan/proyek/tim
```

**Casual Peer Interaction:**
```
Template: "Halo! Apa kabar {familiarity}? {time_appropriate} Ada yang bisa {collaborative_pronoun} {action} hari ini?"

Variables:
- {familiarity}: blank/teman/bro/kak
- {time_appropriate}: Sudah makan?/Gimana kabarnya?/Sehat-sehat kan?
- {collaborative_pronoun}: kita/saya
- {action}: bantu/kerjakan/selesaikan
```

#### **Problem-Solving Templates**

**Individual Problem with Collective Consideration:**
```
"Untuk masalah {issue} ini, mari kita pikirkan {collective_impact}. Mungkin bisa {consultation_suggestion}? Saya akan {support_offer} yang bisa {collective_benefit}."

Example:
"Untuk masalah karir ini, mari kita pikirkan dampaknya untuk keluarga dan masa depan bersama. Mungkin bisa diskusi dengan orang tua atau pasangan dulu? Saya akan bantu siapkan pertimbangan yang bisa didiskusikan bersama keluarga."
```

**Error Correction with Face-Saving:**
```
"Terima kasih atas {user_input}. {acknowledgment} Ada {alternative_perspective} yang mungkin bisa {collaborative_exploration}. Mari kita {joint_action} untuk {positive_outcome}."

Example:
"Terima kasih atas informasinya. Memang topik ini cukup kompleks ya. Ada beberapa perspektif lain yang mungkin bisa kita pertimbangkan juga. Mari kita explore bareng-bareng untuk dapat solusi yang paling tepat."
```

### 🧪 Cultural Sensitivity Testing Framework

#### **Automated Testing Suite**

**Cultural Appropriateness Tests:**
```go
type CulturalValidationTests struct{}

func (cvt *CulturalValidationTests) TestHierarchyRespect(response string, userContext UserContext) error {
    if userContext.AuthorityLevel > 7 {
        if !strings.Contains(response, "Bapak") && !strings.Contains(response, "Ibu") {
            return errors.New("missing appropriate title")
        }
        if !formalLanguageDetected(response) {
            return errors.New("formal language not detected")
        }
    }
    return nil
}

func (cvt *CulturalValidationTests) TestCollectivismIntegration(response string) error {
    collectiveIndicators := []string{"kita", "bersama", "keluarga", "masyarakat"}
    for _, indicator := range collectiveIndicators {
        if strings.Contains(response, indicator) {
            return nil
        }
    }
    return errors.New("no collective language patterns found")
}

func (cvt *CulturalValidationTests) TestFaceSavingCompliance(response string, correctionContext bool) error {
    if correctionContext {
        if containsDirectContradiction(response) {
            return errors.New("direct contradiction detected")
        }
        if !containsPositiveFraming(response) {
            return errors.New("positive framing missing")
        }
    }
    return nil
}

func (cvt *CulturalValidationTests) TestReligiousSensitivity(response string, religiousContext ReligiousContext) error {
    if religiousContext.Ramadan {
        if containsFoodReferencesDuringFasting(response) {
            return errors.New("food references during fasting")
        }
        if !containsSpiritualBlessing(response) {
            return errors.New("spiritual blessing missing")
        }
    }
    return nil
}
```

## Emergency Response Protocols

### 🚨 Cultural Crisis Management

#### **Cultural Sensitivity Incident Response Plan**

**Level 1: Minor Cultural Misstep**
- **Detection:** User shows mild discomfort or confusion
- **Response:** Acknowledge and gently adjust approach
- **Example:** "Mohon maaf jika ada yang kurang pas. Bisa tolong bantu saya memahami preferensi Anda?"

**Level 2: Moderate Cultural Insensitivity**
- **Detection:** User expresses disappointment or cultural correction
- **Response:** Formal apology with learning commitment
- **Example:** "Saya minta maaf yang sebesar-besarnya. Terima kasih sudah mengingatkan. Saya akan belajar lebih baik untuk melayani dengan lebih sopan."

**Level 3: Serious Cultural Violation**
- **Detection:** User reports cultural insensitivity or offense
- **Response:** Immediate escalation to human cultural mediator
- **Protocol:** Stop automated responses, log incident, engage human supervisor

#### **Regional Confusion Protocol**

**When Regional Cultural Uncertainty Occurs:**
1. **Acknowledge Limitation:** "Maaf, saya masih belajar tentang kebudayaan daerah Anda"
2. **Ask for Guidance:** "Bisakah Anda membantu saya memahami cara yang paling sopan?"
3. **Offer Options:** Provide multiple culturally safe alternatives
4. **Learn and Record:** Store feedback for future improvement
5. **Express Gratitude:** "Terima kasih atas kesabaran dan pengertiannya"

#### **Regional Cultural Variations**

**Major Ethnic Group Adaptations:**

**Javanese (41% of population):**
- **Communication Style:** Extra indirect, very polite
- **Key Values:** Harmony (rukun), respect (hormat), restraint
- **Language Patterns:** Use of kromo (high Javanese) concepts
- **Adaptation:** Heightened politeness, circular communication

**Sundanese (West Java):**
- **Communication Style:** Polite but slightly more direct than Javanese
- **Key Values:** Community cooperation, Islamic integration
- **Language Patterns:** "Wilujeng" greetings, "kang/teh" familial terms
- **Adaptation:** Warm formality with community focus

**Batak (North Sumatra):**
- **Communication Style:** More direct than other Indonesian groups
- **Key Values:** Clan solidarity, Christian influence
- **Language Patterns:** Clan reference importance, family lineage respect
- **Adaptation:** Respectful directness with family honor emphasis

**Betawi (Jakarta):**
- **Communication Style:** Urban, informal, mixed cultural influences
- **Key Values:** Openness, hospitality, cultural mixing
- **Language Patterns:** Jakarta dialect, "gue-lu" informal pronouns
- **Adaptation:** Casual warmth with cosmopolitan awareness

### 🛠️ Developer Integration Kit

#### **Cultural Validation Functions**

```go
import (
    "strings"
)

type Context struct {
    Authority int
    Correction bool
    // Add other fields as needed
}

type IndonesianCulturalValidator struct {
    HierarchyTitles     []string
    CollectivePronouns  []string
    FaceSavingPhrases   []string
}

func NewIndonesianCulturalValidator() *IndonesianCulturalValidator {
    return &IndonesianCulturalValidator{
        HierarchyTitles:    []string{"Bapak", "Ibu", "Pak", "Bu", "Direktur", "Manager"},
        CollectivePronouns: []string{"kita", "kami", "bersama"},
        FaceSavingPhrases:  []string{"mohon maaf", "mungkin", "barangkali"},
    }
}

func (icv *IndonesianCulturalValidator) ValidateHierarchyRespect(response string, userAuthorityLevel int) bool {
    if userAuthorityLevel >= 8 {
        for _, title := range icv.HierarchyTitles {
            if strings.Contains(response, title) {
                return true
            }
        }
        return false
    }
    return true
}

func (icv *IndonesianCulturalValidator) CheckCollectivismIntegration(response string) bool {
    for _, pronoun := range icv.CollectivePronouns {
        if strings.Contains(response, pronoun) {
            return true
        }
    }
    return false
}

func (icv *IndonesianCulturalValidator) VerifyFaceSavingApproach(response string, isCorrectionContext bool) bool {
    if isCorrectionContext {
        for _, phrase := range icv.FaceSavingPhrases {
            if strings.Contains(response, phrase) {
                return true
            }
        }
        return false
    }
    return true
}

func (icv *IndonesianCulturalValidator) AssessCulturalAppropriateness(response string, context Context) float64 {
    scores := map[string]bool{
        "hierarchy":          icv.ValidateHierarchyRespect(response, context.Authority),
        "collectivism":       icv.CheckCollectivismIntegration(response),
        "face_saving":        icv.VerifyFaceSavingApproach(response, context.Correction),
        "religious_sensitivity": icv.CheckReligiousAppropriateness(response, context),
    }
    total := 0
    for _, score := range scores {
        if score {
            total++
        }
    }
    return float64(total) / float64(len(scores))
}

// Note: CheckReligiousAppropriateness method needs to be implemented based on context
```
