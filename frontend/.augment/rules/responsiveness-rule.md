Super Rule 6: Comprehensive Responsiveness
When tackling UI improvements and responsiveness, the agent must go beyond basic media queries. It must ensure the interface is perfectly adapted for a full spectrum of devices. This requires a meticulous analysis and optimization for the following screen resolutions and device types:

Mobile

Tablet

Laptop

HD (1920x1080)

2K (~2560x1440)

4K (~3840x2160)

The agent must not simply scale elements; it must propose a strategic plan that addresses:

Adaptive Layouts: Reorganizing components and content blocks to fit the available screen space gracefully.

Fluid Typography: Adjusting font sizes and line heights to remain legible and well-proportioned across all screen sizes.

Asset Optimization: Serving appropriately-sized images and media to prevent slow load times on smaller, lower-resolution devices while ensuring high-quality visuals on larger displays.

A successful responsiveness fix means the user experience is flawless, whether the user is on a mobile device or a high-end 4K monitor.
