## 📋 Overview

Sellica is a powerful Civil Records Management System built using Next.js, React, TypeScript, and Tailwind CSS. It provides a comprehensive set of features for managing civil records data, tracking activities, and generating reports. With its intuitive interface and robust functionality, Sellica streamlines administrative processes and enhances data accuracy.

## 🚀 Features

### 📊 Interactive Dashboard
- Visual representation of key metrics and statistics
- Real-time updates and notifications
- Customizable widgets and charts

### 📝 Data Management Modules
- **Salah Rekam** - Manage incorrect civil record entries
- **Adjudicate Record** - Process record adjudication requests
- **Duplicate Operator** - Identify and handle duplicate entries
- **Pengajuan Bulanan** - Manage monthly submissions

### 👤 User Profile Management
- Secure authentication and authorization
- Profile settings and preferences
- Avatar and personal information management

### 📈 Activity Tracking
- **Aktivitas SIAK** - Monitor SIAK system activities
- **Aktivitas User** - Track user activities and audit logs
- **Dokumentasi** - Document management and version control

### 🔄 Administrative Tools
- Advanced search and filtering
- Bulk operations and data export
- Reporting and analytics

## 🛠️ Installation

1. Clone the repository:
```bash
git clone https://github.com/your-organization/sellica-prop.git
cd sellica-prop
```

2. Install dependencies:
```bash
npm install
# or
yarn install
```

3. Configure environment variables:
```bash
cp .env.example .env.local
# Edit .env.local with your configuration
```

4. Run the development server:
```bash
npm run dev
# or
yarn dev
```

5. Open [http://localhost:3000](http://localhost:3000) in your browser to see the application.

## 🧰 Tech Stack

- **Frontend**: Next.js, React, TypeScript, Tailwind CSS, Framer Motion
- **State Management**: React Context API
- **Database**: Supabase (PostgreSQL)
- **Authentication**: Supabase Auth
- **Styling**: Tailwind CSS with Dark Mode support
- **UI Components**: Custom components and shadcn/ui
